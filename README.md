# 📊 PhonePe Transaction Analysis Dashboard

## 📌 Project Overview

This project is an interactive **PhonePe Transaction Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes transaction data to understand transaction trends, transaction value, user contribution, payment status, age-segment contribution, service-wise transaction value, and weekday vs. weekend usage.

The goal of this project is to transform raw transaction data into an interactive dashboard that helps identify important patterns and trends in digital payment activity.

---

## 🎯 Objectives

- Analyze overall transaction volume and transaction value.
- Track transaction trends over time.
- Analyze payment status across transactions.
- Understand user contribution and transaction value.
- Analyze transaction contribution across different age segments.
- Compare transaction value across different services.
- Compare weekday and weekend transaction activity.
- Identify top users based on transaction value.
- Build an interactive dashboard using Power BI filters.

---

## 📊 Dashboard Features

### 1. Overall KPIs

The dashboard provides key performance indicators including:

- Total Transactions
- Total Transaction Value
- Unique Users
- Successful Rate

### 2. Transaction Trend Analysis

A monthly trend chart is used to analyze how transaction activity changes over time and identify periods of higher or lower transaction volume.

### 3. Payment Status Analysis

Transactions can be analyzed using payment-status filters:

- Successful
- Failed
- Pending

This allows transaction activity to be explored based on payment status.

### 4. Age Segment Contribution

The dashboard analyzes user contribution across different age segments and shows the percentage contribution of each segment.

### 5. Service Transaction Value Analysis

Transaction value is compared across different services, including:

- Insurance
- Money Transfer
- Recharge Bills

### 6. Top 5 Users

The dashboard identifies the top 5 users based on transaction value.

### 7. Weekday vs Weekend Analysis

Transaction activity is compared between weekdays and weekends to understand usage patterns.

### 8. Interactive Filters

The dashboard includes interactive filters that allow users to analyze the data dynamically by:

- Month
- Payment Status

## 🔍 Key Analysis Areas

The dashboard can be used to investigate questions such as:
